# Pharma Product Sales Analysis – Power BI

## 📊 Project Overview

This project is an interactive Power BI dashboard developed to analyze pharmaceutical sales performance across products, product classes, years, countries, and distribution channels.

The dashboard helps identify top-performing products, sales trends, product-class performance, and overall sales and quantity metrics.

## 🎯 Business Objective

The objective of this project is to transform raw pharmaceutical sales data into an interactive business intelligence dashboard that can help stakeholders:

- Identify the highest-selling products
- Analyze yearly sales trends
- Compare product classes
- Monitor total sales and quantity
- Analyze sales across different countries
- Compare Hospital and Pharmacy channels
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization
- Business Intelligence

## 📈 Dashboard Features

The dashboard includes:

- Total Sales KPI
- Total Quantity KPI
- Average Price KPI
- Top 5 Products by Sales
- Sales Trend by Year
- Sales by Product Class
- Country filter
- Year range filter
- Sales Channel filter

## 🔍 Key Insights

The dashboard provides insights into:

- The products generating the highest sales revenue
- Changes in sales performance across different years
- Product classes contributing the most to overall sales
- Differences in performance between countries
- Differences between Hospital and Pharmacy sales channels
- Overall sales volume and quantity

## 📊 Dashboard

The Power BI dashboard provides an interactive interface where users can apply filters for:

- Country
- Year
- Channel

and dynamically analyze the corresponding sales metrics and visualizations.

## 📁 Project Files

- `pharma-sales-analysis.pbix` – Power BI dashboard file

## 🚀 How to Use

1. Download the `pharma-sales-analysis.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Use the available filters to explore the data.
4. Interact with the charts and KPI cards to analyze sales performance.
